### 🧭 Quickstart Guides

#### 1. Installing FreeBuff
FreeBuff can be quickly deployed on Windows systems to optimize performance:
1. **Download:** Grab the latest release package or installer from the official repository.
2. **Execute:** Run the installer or script with administrator privileges to apply recommended system and network tweaks.
3. **Configure:** Launch FreeBuff from your desktop or system tray to adjust buffer thresholds and monitor performance metrics in real-time.

#### 2. Installing OpenCode CLI
Get up and running with OpenCode CLI in your terminal environment:
* **Using Node.js / NPM (Recommended):**
  ```bash
  npm install -g opencode-cli

```

* **Verification:** Confirm the installation by running:
```bash
opencode --version

```


* **Initialization:** Set up your default workspace profile with:
```bash
opencode init

```

## 🪟 Windows Customization Philosophy

The Windows customization tools in this repository align particularly well with the **JohnLC Aura Design Philosophy**:

```text
                    JOHNLC AURA
                         │
            ┌────────────┼────────────┐
            │            │            │
            ▼            ▼            ▼
        VISUAL        MOTION       FUNCTION
            │            │            │
            ▼            ▼            ▼
       Glass / Blur   Animation   PowerToys
       Transparency   Effects     Windhawk
       Custom Themes  Feedback    TranslucentTB
            │                         │
            └────────────┬────────────┘
                         ▼
                 PERSONAL COMPUTING
                         │
                         ▼
             "See the world from a
               different perspective."
```

The goal is not simply to make Windows look different.

The goal is to create a **personal computing environment** that feels:

* Personal
* Functional
* Beautiful
* Responsive
* Customizable
* Immersive
* Efficient

Microsoft describes PowerToys as a collection of utilities intended to help power users customize Windows, improve workflows, and remove friction from everyday tasks.

Windhawk similarly focuses on customizable Windows mods while emphasizing transparency through reviewable source code and attention to stability and performance.
